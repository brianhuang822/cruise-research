Cruise lines change gratuities and inclusions often. Each cabin lists its sources and the date they were checked. Confirm details with the cruise line before you book. Fares are median prices for each ship and cabin tier and are not quotes for a specific sailing.

To rebuild the data, run python3 scripts/build.py. It reads the curated CSV files plus dated snapshots from the CDC Vessel Sanitation Program and Wikidata, and writes data/dataset.json.
